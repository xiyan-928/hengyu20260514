# UI布局优化 - 传感器卡片调整

## 修改概述
根据用户要求："每个传感器卡片单独占用一个整行，绘图控件填充卡片控件，并减小卡片的高度，更加美观"

## 主要改动

### 1. 布局结构调整
**文件**: `lib/widgets/sensor_data_widget.dart`

**从 GridView 改为 Column**:
- **之前**: 使用 `GridView.builder` 2x2 网格布局
- **现在**: 使用 `Column` 垂直布局，每个传感器卡片占用一整行

```dart
// 之前的GridView
GridView.builder(
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    childAspectRatio: 1.2,
    crossAxisSpacing: 12,
    mainAxisSpacing: 12,
  ),
  ...
)

// 现在的Column
Column(
  children: widget.sensorData.entries.map((entry) {
    return Padding(
      padding: const EdgeInsets.only(bottom: 12),
      child: _buildSensorCard(entry.key, entry.value),
    );
  }).toList(),
)
```

### 2. 卡片布局优化

**新的卡片设计**:
- **固定高度**: 120px (减小了卡片高度)
- **水平布局**: 左右分区设计
- **左侧区域 (2/5)**: 传感器信息和当前值
- **右侧区域 (3/5)**: 图表区域填充剩余空间

**布局结构**:
```
┌─────────────────────────────────────────────────┐
│ [图标] 传感器名称              │     图表区域     │
│                               │                 │
│ 25.6°C                        │    ~~~∿∿∿~~~    │
│ 12:30:45                      │   ∿∿∿~~~~∿∿∿   │
└─────────────────────────────────────────────────┘
```

### 3. 视觉改进

**传感器信息区域**:
- 增大了数值字体大小: 16px → 20px
- 提升了标题字体大小: 11px → 13px
- 更好的信息层次和可读性

**图表区域**:
- 图表高度: 96px (充分利用卡片空间)
- 图表宽度: 自适应填充右侧区域
- 保持了所有优化的性能特性

## 优势

✅ **空间利用**: 每个传感器占用一整行，显示更清晰
✅ **可读性**: 更大的数值显示，更容易阅读
✅ **图表空间**: 图表有更多水平空间显示趋势
✅ **美观度**: 紧凑的120px高度，整体更美观
✅ **响应式**: 自适应不同屏幕宽度

## 布局对比

**之前**: 2x2网格，4个传感器挤在一屏
**现在**: 垂直列表，每个传感器一行，信息更清晰

这种新布局特别适合:
- 移动设备的垂直滚动体验
- 传感器数据的详细查看
- 实时趋势图的横向展示
