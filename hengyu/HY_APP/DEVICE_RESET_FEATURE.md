# 设备重置功能 - 使用说明

## 概述

设备重置功能允许用户手动或自动重置HY设备，以解决传感器读取错误等问题。该功能集成在硬件控制页面中。

## 主要功能

### 1. 设备模式检测
- 自动检测设备是否运行在真实硬件模式或模拟模式
- 显示当前设备模式状态（真实模式/模拟模式）

### 2. 手动重置
- **寄存器地址设置**：可输入0-7范围内的整数，指定重置操作的寄存器地址
- **开始重置按钮**：手动触发设备重置操作
- **重置进度条**：实时显示重置操作的进度和剩余时间

### 3. 自动重置
- **自动重置开关**：可开启/关闭自动重置功能
- **错误阈值监控**：当传感器读取错误累计达到3次时，自动触发重置
- **智能重置流程**：
  - 停止所有传感器和光谱采集
  - 执行设备重置操作
  - 等待重置完成
  - 自动恢复数据采集

## 使用方法

### 手动重置
1. 打开硬件控制页面
2. 找到"设备重置"区域
3. 设置寄存器地址（0-7）
4. 点击"开始重置"按钮
5. 确认重置操作
6. 等待进度条完成

### 自动重置设置
1. 在"设备重置"区域找到"自动重置"开关
2. 开启开关以启用自动重置功能
3. 系统将自动监控传感器错误次数
4. 当错误累计达到3次时，自动执行重置

## API接口

### 获取设备模式
```
GET /device-mode
```

### 启动设备重置
```
POST /hy-device/reset
{
  "ip": "192.168.1.100",
  "port": 502,
  "register": 5,
  "mock_mode": true
}
```

### 查询重置状态
```
GET /hy-device/reset-status/{task_id}
```

## 技术实现

### 核心组件
- `DeviceResetProvider`: 管理重置状态和配置
- `DeviceResetService`: 处理与后端API的通信
- `DeviceResetWidget`: 用户界面组件
- 错误监控集成在`SensorProvider`和`SpectrumProvider`中

### 自动重置流程
1. 传感器/光谱采集出错时，增加错误计数
2. 达到阈值时，自动触发重置流程：
   - 停止所有worker isolate
   - 调用重置API
   - 轮询重置状态
   - 重置完成后恢复采集

### 状态管理
- `ResetState`: 重置状态（idle, resetting, completed, failed）
- 错误计数器和自动重置阈值管理
- 重置进度和时间估算

## 安全特性

- 重置操作需要用户确认
- 自动重置只在启用时生效
- 重置过程中禁用其他控制操作
- 详细的状态信息和错误提示

## 注意事项

1. 重置操作通常需要30秒以上的时间（实际模式）
2. 模拟模式下重置时间约为5秒
3. 重置过程中请勿关闭应用程序
4. 自动重置功能建议在无人值守时启用
5. 重置完成后，传感器错误计数会自动清零

## 故障排除

### 常见问题
1. **重置启动失败**
   - 检查网络连接
   - 确认后端服务正常运行
   - 验证设备IP地址设置

2. **重置进度长时间无变化**
   - 真实硬件模式下重置需要较长时间
   - 检查设备连接状态
   - 可能需要手动停止并重试

3. **自动重置未触发**
   - 确认自动重置开关已开启
   - 检查错误计数是否达到阈值
   - 验证provider关联是否正确设置

### 调试信息
- 应用程序会在控制台输出详细的重置过程日志
- 错误计数和状态变化都有相应的调试输出
- 可通过DevTools查看provider状态
